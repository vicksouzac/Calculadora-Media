# 📚 Calculadora de Média Escolar

Um script simples em Python para calcular a média final de alunos a partir de 4 notas informadas, determinando a situação acadêmica do estudante de forma prática e automática.

---

## 🚀 Funcionalidades

- **Cálculo da Média:** Entrada de 4 notas com cálculo automático da média aritmética.
- **Status do Aluno:** 
  - **Aprovado:** Média igual ou superior a 7.0.
  - **Recuperação:** Média entre 4.5 e 6.9.
  - **Reprovado:** Média abaixo de 4.5.
- **Execução Contínua:** Permite realizar múltiplos cálculos em sequência sem precisar reiniciar o script.
